# 🏕️ 12/11~12/13 三天兩夜情侶露營精選企劃 (Camping Project)

本專案為針對 **2026/12/11 (五) ～ 12/13 (日)** 三天兩夜情侶露營精心調研整理之互動式 GIS 選址工具與企劃檔案。

---

## 🎯 核心需求指標

1. **地理範圍**：台中（含）以北（新竹、苗栗、桃園）。
2. **營位隱私與空間**：**真・單帳一區 / 獨立景觀大包區**，階梯或林木遮蔽，空間開闊（杜絕密集營位與鄰帳干擾）。
3. **體驗標竿**：對標上次露營好評經驗——**「桃園復興沒搞頭露營區 G區」**（大空間、坐擁開闊山嵐風景、隱私極佳、車停帳邊）。
4. **免搭帳輕露營**：營區提供**代搭帳服務或已搭設好之風格帳篷（附床墊）**，自煮炊事保留野趣。
5. **必備硬體**：冷熱飲水機、五星級乾淨衛生衛浴（無異味、熱水強勁）。
6. **★ 加分項**：**洗手台水槽具備溫熱水**（寒冬洗菜洗碗去油不凍手）。

## 🗺️ GIS 地圖圖資說明

本專案網頁 (`index.html`) 已串接台灣本地圖資與國際圖資，預設載入 **Google 標準道路圖**，並於右上角提供即時切換控制器：
- **Google 標準道路圖 (Roadmap)**：預設底圖，道路導航與城鄉動線最清晰。
- **Google 地形等高線圖 (Terrain)**：立體山脈等高線，露營看山勢、避風向極為實用。
- **內政部國土測繪中心 (NLSC) 台灣通用電子地圖 (WMTS)**：官方在地最權威圖資。
- **國土測繪中心 衛星正射影像 (PHOTO_MIX)**：高空鳥瞰空拍圖。
- **OpenStreetMap (OSM) 開放街圖**：全球知名開源備援圖磚。
