## 露營樂 1 帳包區查位特別提醒

露營樂網站首頁或月曆總表上顯示的「剩餘帳數」為**全營區總庫存**（例如包含4帳或6帳的大區剩餘數量）。
為了確保選到真・1帳包區：
1. 點擊上述營地之「Easycamp 空位查詢」按鈕進入營位空位表。
2. 按 `>` 切換至 **12 月空位表**。
3. 點選 **2026/12/11 (五)** 與 **12/12 (六)**，並展開分區檢視指定之單帳區名：
   - **木村的家**：請認明「木屋前景觀區」、「B1區」、「B2區」或「B4區」。
   - **夢想家園**：請認明「仁愛區」或「高架區」。
   - **馬嘟溪營地**：請認明「五葉松區(1帳包區)」或「香蕉區(1帳包區)」。
